RAKSOMUSIC WEBSITE

HOW TO USE
1. Keep index.html, styles.css, script.js and the assets folder together.
2. Open index.html in a modern browser.
3. To use the music player, click the play button and choose an audio file from your device.
   The selected audio is only loaded locally in your browser; it is not uploaded anywhere.

CUSTOMISE
- Edit the text and section content in index.html.
- Change colours, spacing and layout in styles.css.
- Replace assets/rakso-hero.jpg with your own artwork (keep the same filename).
- Replace the demo artwork cards with your own portfolio images when ready.

NOTE
The site uses Google Fonts when an internet connection is available. System fallbacks are included.
